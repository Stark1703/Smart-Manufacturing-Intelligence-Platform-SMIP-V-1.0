# 01 — Environment Setup

## Introduction

Before deploying the Smart Manufacturing Intelligence Platform (SMIP) V2, the Databricks environment must be prepared to support data ingestion, Lakeflow Declarative Pipelines, Delta Lake tables, Unity Catalog governance, and Databricks SQL.

This document describes the required software, platform components, permissions, and workspace configuration needed to successfully execute the SMIP V2 project.

---

# Purpose

The objectives of the environment setup are to:

- Configure the Databricks workspace
- Enable Unity Catalog
- Create the required storage locations
- Configure compute resources
- Enable Databricks SQL
- Prepare the Lakeflow execution environment

After completing this setup, the platform will be ready for deployment.

---

# System Requirements

The following components are required before deploying SMIP V2.

| Component | Purpose |
|------------|---------|
| Databricks Workspace | Development and execution environment |
| Unity Catalog | Data governance and storage management |
| Delta Lake | Transactional data storage |
| Lakeflow Declarative Pipelines | Pipeline orchestration |
| Databricks SQL | Dashboard and reporting |
| Git Integration | Source code management |

---

# Workspace Configuration

The project is designed to run entirely within a Databricks workspace.

Typical workspace components include:

```text
Workspace

├── Repos
├── Catalog
├── Compute
├── SQL
├── Pipelines
└── Workflows
```

Each service contributes to the end-to-end manufacturing analytics platform.

---

# Unity Catalog

Unity Catalog provides centralized governance for all datasets created by SMIP V2.

The project stores data using:

- Catalog
- Schema
- Volume
- Managed Delta Tables

Example structure:

```text
Catalog

smip_v2

└── manufacturing

    ├── Bronze Tables

    ├── Silver Tables

    ├── Dimension Tables

    ├── Fact Tables

    └── Gold Tables
```

Unity Catalog ensures secure and consistent access to manufacturing data.

---

# Unity Catalog Volume

Manufacturing event files are stored within a Unity Catalog Volume before ingestion.

Example:

```text
/Volumes/smip_v2/manufacturing/raw_data/
```

This volume acts as the landing zone for raw JSON manufacturing events generated by the simulation engine.

---

# Compute Resources

SMIP V2 uses Databricks compute to execute Lakeflow pipelines.

Typical compute requirements include:

- Serverless or Classic Compute
- Python Runtime
- Spark Runtime
- Delta Lake support

The compute environment should have sufficient resources to process streaming manufacturing events efficiently.

---

# Lakeflow Declarative Pipelines

Lakeflow Declarative Pipelines orchestrate the complete manufacturing analytics workflow.

The pipeline executes the following layers:

```text
Setup

↓

Bronze

↓

Silver

↓

Dimensions

↓

Facts

↓

Gold
```

Dependencies are resolved automatically based on dataset relationships.

---

# Databricks SQL Warehouse

A SQL Warehouse is required to query Gold KPI tables and power the Executive Dashboard.

The SQL Warehouse provides:

- Interactive SQL execution
- Dashboard rendering
- Query acceleration
- Secure access to Unity Catalog tables

---

# Git Integration

The project repository is connected directly to the Databricks workspace using Git integration.

Typical workflow:

```text
GitHub Repository

↓

Databricks Repo

↓

Lakeflow Pipeline

↓

SQL Dashboard
```

Git integration simplifies version control and notebook management.

---

# Repository Structure

After cloning the repository, the Databricks branch should contain the following structure.

```text
databricks/

└── notebooks/

    ├── 00_setup

    ├── 01_bronze

    ├── 02_silver

    ├── 03_dimensions

    ├── 04_facts

    ├── 05_gold

    ├── 06_sql_dashboard

    └── 07_validation
```

Each folder corresponds to one stage of the Lakehouse pipeline.

---

# Required Permissions

The executing user should have permissions to:

- Read and write Unity Catalog tables
- Create managed Delta tables
- Execute Lakeflow pipelines
- Access Databricks SQL
- Read Unity Catalog Volumes
- Manage pipeline execution

These permissions ensure successful deployment and operation.
