# 04 — Dashboard Usage

## Introduction

The Executive Dashboard is the primary business interface of the Smart Manufacturing Intelligence Platform (SMIP) V2.

It provides a centralized view of manufacturing operations by presenting key performance indicators (KPIs) through interactive charts, tables, and summary metrics.

This guide explains how business users can navigate the dashboard, interpret manufacturing KPIs, apply filters, and use the available visualizations to support operational decision-making.

---

# Dashboard Overview

The Executive Dashboard consolidates manufacturing information from the Gold KPI layer into a single interactive report.

The dashboard currently contains the following analytical sections:

- Factory Summary
- Production Analysis
- Machine Performance
- Quality Monitoring
- Material Traceability
- Packaging Performance

Together, these sections provide a complete overview of factory operations.

---

# Opening the Dashboard

Navigate to:

```text
Databricks SQL

↓

Dashboards

↓

Executive Dashboard
```

The dashboard automatically loads the latest KPIs generated by the Lakeflow Declarative Pipeline.

# Factory Summary

The Factory Summary appears at the top of the dashboard and provides an overview of manufacturing activity.

Typical KPI cards include:

- Operations Completed
- Tests Completed
- Products Started
- Material Scans
- Packages Completed
- Quality Pass Rate

### Purpose

This section enables managers to assess overall factory performance within a few seconds.

Typical questions answered include:

- How much production has been completed?
- How many inspections have been performed?
- Is manufacturing progressing as expected?

---

# Production Analysis

The Production section visualizes manufacturing output across products.

Typical visualization:

- Production by Product

### Purpose

Supports:

- Production planning
- Product mix analysis
- Throughput monitoring

Typical business questions:

- Which products have the highest production volume?
- How is production distributed across product families?

---

# Machine Performance

### Purpose

Supports:

# Dashboard Filters

The Executive Dashboard includes interactive filters that allow users to focus on specific manufacturing data.

Current filters include:

| Filter | Description |
|----------|-------------|
| Product Name | View metrics for a selected product |
| Supplier | Filter by material supplier |
| Planned Shift | Analyze production by work shift |

Applying a filter automatically updates all dashboard visualizations.

---

# Interpreting KPIs

The dashboard presents aggregated manufacturing metrics rather than raw operational data.

Example interpretation:

| KPI | Business Meaning |
|------|------------------|
| Operations Completed | Total manufacturing operations performed |
| Average Cycle Time | Average duration of production operations |
| Quality Pass Rate | Percentage of successful inspections |
| Material Scans | Number of production materials scanned |
| Packages Completed | Finished products ready for shipment |

These KPIs provide an overview of factory performance without requiring detailed engineering knowledge.

# Dashboard Refresh

The dashboard displays metrics generated from the Gold KPI tables.

Whenever the Lakeflow pipeline processes new manufacturing events, the KPI tables are refreshed automatically.

```text
Manufacturing Events

↓

Lakeflow Pipeline

↓

Gold KPI Tables

↓

Executive Dashboard
```

Users do not need to refresh the underlying datasets manually.

# Best Practices

To obtain the most value from the dashboard:

- Review KPI cards before analyzing detailed charts.
- Apply filters to investigate specific products or suppliers.
- Compare machine performance to identify operational differences.
- Monitor production output regularly.
- Verify quality and packaging metrics before shipment.

Following these practices helps users identify trends and respond to operational issues more effectively.
