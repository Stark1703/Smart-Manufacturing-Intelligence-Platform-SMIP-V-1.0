# Silver Layer

## Purpose

The Silver Layer transforms raw Bronze data into structured, validated datasets suitable for analytics.

This layer applies business rules, standardization, and dimensional modeling.

---

## Processing

Main activities include:

- Data quality validation
- Null handling
- Standardization
- Type conversion
- Relationship validation
- Dimension creation
- Fact table creation

---

## Dimension Tables

- Products
- Machines
- Operators
- Tools
- Factory

---

## Fact Tables

- Production
- Press Operations
- Quality
- Force Curves

---

## Benefits

- Improved data quality
- Consistent business logic
- Simplified reporting
- Reduced duplication
