# Contributing

## Overview

Contributions are welcome to improve SMIP.

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Implement changes.
4. Test your code.
5. Submit a Pull Request.

## Guidelines

- Follow coding standards.
- Keep commits focused.
- Update documentation.
- Include tests when appropriate.

## Reporting Issues

Provide:

- Environment
- Steps to reproduce
- Expected behavior
- Actual behavior
