# 🔄 Manufacturing Workflow

## Overview

The Smart Manufacturing Intelligence Platform (SMIP) simulates the complete lifecycle of a manufactured product within a modern Manufacturing Execution System (MES).

The workflow begins with production planning and ends with packaging, generating realistic manufacturing events and datasets that mirror industrial production processes.

The simulation is designed to demonstrate:

- Enterprise Resource Planning (ERP)
- Manufacturing Execution Systems (MES)
- Factory Digital Twin
- Industrial IoT (IIoT)
- Manufacturing Traceability
- Quality Management
- Production Analytics

# Workflow Stages

The manufacturing simulation consists of nine sequential stages.

---

# Stage 1 — Production Planning

## Module

```text
simulate_work_orders.py
```

## Purpose

Generate ERP work orders representing planned manufacturing demand.

Each work order contains:

- Work Order ID
- SAP Order Number
- Product Code
- Quantity
- Planned Start
- Planned Finish
- Production Line
- Planned Shift

### Output

```
work_orders.csv
```

---

# Stage 2 — Production Execution

## Module

```text
generate_production_executions.py
```

## Purpose

Convert ERP work orders into Manufacturing Execution System (MES) production executions.

Each execution contains:

- Execution ID
- Work Order ID
- Product Code
- Production Line
- Planned Shift
- Execution Start
- Execution End
- Status

### Output

```
production_executions.csv
```

---

# Stage 3 — Operator Login

## Module

```text
simulate_operator_login.py
```

## Purpose

Assign operators to production executions.

Each login session records:

- Login ID
- Operator
- Machine
- Production Execution
- Login Time
- Logout Time

### Output

```
operator_logins.csv
```

---

# Stage 4 — Material Scan

## Module

```text
simulate_material_scan.py
```

## Purpose

Simulate barcode or RFID scanning of materials before manufacturing begins.

Each scan records:

- Material Number
- Supplier
- Batch Number
- Scan Timestamp
- Associated Serial Number

### Output

```
material_scans.csv
```

---

# Stage 5 — Serial Number Generation

## Module

```text
generate_serial_numbers.py
```

## Purpose

Assign a unique serial number to every manufactured unit.

Each serial number links:

- Work Order
- Production Execution
- Product
- Manufacturing Date

This creates the foundation for complete product genealogy.

### Output

```
serial_numbers.csv
```

---

# Stage 6 — Press Operations

## Module

```text
simulate_press_operations.py
```

## Purpose

Simulate press-fit manufacturing operations.

Each manufactured unit performs four press-fit operations.

Each operation records:

- Press Operation ID
- Serial Number
- Machine
- Tool
- Press Program
- Target Force
- Measured Force
- Cycle Time
- Result

### Output

```
press_operations.csv
```

---

# Stage 7 — Force Curve Simulation

## Module

```text
simulate_force_curves.py
```

## Purpose

Generate high-frequency Industrial IoT force-displacement measurements for every press operation.

Each press operation generates:

- 500 sample points

Each point records:

- Force
- Displacement
- Timestamp

### Output

```
force_curves.csv
```

### Generated Dataset

Approximately:

- 3.6 million force curve points

This represents the largest dataset generated by the platform.

---

# Stage 8 — Manufacturing Testing

## Module

```text
simulate_testing.py
```

## Purpose

Simulate product quality inspections using predefined test programs.

Each manufactured unit performs multiple quality tests.

Recorded information:

- Test Program
- Target Value
- Measured Value
- PASS / FAIL
- Start Time
- End Time

### Output

```
testing_results.csv
```

---

# Stage 9 — Packaging

## Module

```text
simulate_packaging.py
```

## Purpose

Prepare finished products for shipment.

Each package records:

- Package ID
- Serial Number
- Package Type
- Dimensions
- Weight
- Packaging Time
- Packaging Status

### Output

```
packaging.csv
```

# Manufacturing Traceability

Every manufactured unit can be traced throughout its lifecycle.

```text
Product
    │
    ▼
Work Order
    │
    ▼
Execution
    │
    ▼
Serial Number
    │
    ├── Material Batch
    ├── Operator
    ├── Machine
    ├── Tool
    ├── Press Program
    ├── Force Curves
    ├── Test Results
    └── Packaging
```

This enables complete product genealogy and supports quality investigations, production analysis, and regulatory traceability.
