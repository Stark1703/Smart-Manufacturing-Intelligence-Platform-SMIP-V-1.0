# SQL Views

## Overview

SQL Views provide a semantic layer between the Gold Delta tables and business intelligence tools.

The views simplify data access and expose business-friendly datasets for reporting.

---

## Views

- vw_production_summary
- vw_quality_summary
- vw_oee_summary
- vw_traceability_summary
- vw_executive_summary

---

## Purpose

SQL Views:

- Hide implementation details
- Simplify Power BI integration
- Provide stable reporting interfaces
- Reduce query complexity

---

## Consumer

Power BI connects directly to these SQL Views using the Databricks SQL Warehouse.
