# Coding Guidelines

## Overview

SMIP follows consistent coding standards to improve readability, maintainability, and collaboration.

## Python Style

- Python 3.13+
- Type hints
- Dataclasses
- Enum classes
- PEP 8 formatting

## Naming Conventions

| Item | Convention |
|--------|------------|
| Variables | snake_case |
| Functions | snake_case |
| Classes | PascalCase |
| Constants | UPPER_CASE |

## Documentation

Each module includes:

- Purpose
- Author
- Version

Functions include docstrings.

## Logging

Use the standard logging module instead of print statements.

## Comments

Prefer descriptive code over excessive comments.
